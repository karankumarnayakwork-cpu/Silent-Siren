📌 Project Description

Silent Siren is a real-time gesture-based emergency alert system built using OpenCV, MediaPipe, and Python. The system is designed to assist individuals in distress situations where verbal communication may not be possible.

It continuously monitors hand gestures through a camera feed and detects a predefined “help” sign. Upon recognition, the system automatically triggers an emergency response by placing a call to a registered contact using integrated communication services and activating a loud siren to attract nearby attention.

This project demonstrates the practical application of computer vision and AI in enhancing personal safety and emergency response systems.

⚙️ Key Features
✋ Real-time hand gesture detection
🧠 Accurate gesture recognition using MediaPipe
📞 Automatic emergency calling system
🔊 Siren alert for immediate attention
⚡ Fast and responsive processing with OpenCV
🎯 Use Cases
Personal safety for individuals in danger
Assistance for people with speech or mobility limitations
Emergency signaling in isolated environments
Smart surveillance and safety systems
